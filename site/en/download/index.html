The first release is being prepared

Until then, build MemorY from source.You need Go 1.26 or later, git and make.

$ git clone https://github.com/agenticode/my
$ cd my
$ make build    # bin/my

The build is one file, bin/my.It is built with CGO_ENABLED=0, so no C compiler is needed.
