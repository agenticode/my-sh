릴리스 정보(release.json)를 읽지 못했습니다.파일은 GitHub 릴리스에서 받습니다.

Linux와 macOS 터미널에서 한 줄로 설치합니다.

$ curl -fsSL https://my.sh/get | sh

스크립트가 하는 일과 그 내용: 설치 스크립트파일별 크기와 SHA-256: 릴리스 파일

설치

설치 스크립트

이 기기에 맞는 압축 파일과 SHA256SUMS를 GitHub 릴리스에서 HTTPS로 받습니다.압축 파일의 SHA-256이 SHA256SUMS와 release.json의 값에 모두 맞을 때만 설치합니다.하나라도 다르면 멈추고 아무것도 설치하지 않습니다.

my는 ~/.local/bin에 둡니다.sudo를 쓰지 않고 셸 설정 파일도 고치지 않습니다.그 디렉터리가 PATH에 없으면 추가할 줄을 출력합니다.끝으로 my version을 실행합니다.

MY_INSTALL_DIR
설치할 디렉터리
MY_VERSION
설치할 버전. 이때는 GitHub의 SHA256SUMS로만 확인합니다.
$ curl -fsSL https://my.sh/get | MY_VERSION=<버전> sh

실행하기 전에 읽어 보려면 파일로 받습니다.

$ curl -fsSL https://my.sh/get -o get.sh
$ less get.sh
$ sh get.sh

지금 my.sh/get이 내보내는 스크립트입니다.

파일

릴리스 파일

압축 파일마다 my 실행 파일, LICENSE, README.md가 들어 있습니다.바이너리는 정적 링크라서 따로 설치할 라이브러리가 없습니다.

  • Linux x86-64

    크기
    SHA-256

  • Linux ARM64

    크기
    SHA-256

  • macOS, Apple 실리콘

    케이스 번들을 열고 보고서를 쓰는 용도입니다.

    크기
    SHA-256

체크섬 목록: SHA256SUMS

확인

받은 파일 확인

압축 파일과 SHA256SUMS를 같은 디렉터리에 받습니다.sha256sum -c가 목록의 값과 파일을 맞춰 봅니다.

$ curl -fLO https://github.com/agenticode/my/releases/download/<버전>/my_<버전>_linux_amd64.tar.gz
$ curl -fLO https://github.com/agenticode/my/releases/download/<버전>/SHA256SUMS
$ sha256sum -c --ignore-missing SHA256SUMS
my_<버전>_linux_amd64.tar.gz: OK
$ tar -xzf my_<버전>_linux_amd64.tar.gz
$ my_<버전>_linux_amd64/my version

--ignore-missing은 받지 않은 파일의 줄을 건너뜁니다.sha256sum이 없는 macOS에서는 shasum -a 256 -c --ignore-missing SHA256SUMS를 씁니다.

브라우저로 받은 압축 파일에는 macOS가 격리 속성을 붙이고, 풀면 my에도 붙습니다.이 바이너리는 Apple 공증을 받지 않아서, 그 속성이 있으면 macOS가 실행을 막습니다.풀고 나서 지웁니다: xattr -d com.apple.quarantine my_<버전>_darwin_arm64/mycurl로 받은 파일에는 이 속성이 붙지 않습니다.

소스

소스에서 빌드

필요한 것: Go 1.26 이상, git, make

$ git clone --depth 1 --branch <버전> https://github.com/agenticode/my
$ cd my
$ make build    # bin/my

빌드 결과는 bin/my 파일 하나입니다.CGO_ENABLED=0으로 빌드하므로 C 컴파일러는 필요 없습니다.
