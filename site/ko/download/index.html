그때까지는 소스에서 빌드합니다.필요한 것: Go 1.26 이상, git, make

$ git clone https://github.com/agenticode/my
$ cd my
$ make build    # bin/my

빌드 결과는 bin/my 파일 하나입니다.CGO_ENABLED=0으로 빌드하므로 C 컴파일러는 필요 없습니다.
